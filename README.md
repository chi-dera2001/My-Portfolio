# My-Portfolio

### Project Tittle: Health Insurance Data Analysis

### Project Overview
---
This Project analyzes a health insurance dataset using Microsoft Excel,SQL, and Power BI to uncover meaningful insights into into patients demographics, healthcare cost, lifestyle factors, and insurance charges. The project involved data cleaning, exploratory data analysis, SQL querying, and the creation of an interactive Power BI dashboard. The goal was to identify patterns, trends that can support data-driven decision-making in the healthcare and insurance sectors.

### Data Sources
---
##### Kaggle - Health Insurance Dataset
This publicly available dataset contains information on individuals demographics, lifestyle factors, and medical insurance charges. it was used to explore relationships between variables and identify factors that influence healthcare costs.
